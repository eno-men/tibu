# Web Projeleri Tanıtımları

Bu depo, bağımsız web projeleri hakkında kısa ve bilgilendirici tanıtım yazılarını içerir. Kaynak kod paylaşımı amacı taşımaz.

## YemekGazi
Gazi Üniversitesi yemek menüsünü daha kolay takip etmeye yardımcı olan bağımsız web uygulaması.

**Site:** [YemekGazi](https://yemekgazi.vercel.app/)

## OtobüsYorum
Otobüs firmaları ve otogarları yolcu değerlendirmeleri, puanlar ve karşılaştırılabilir bilgilerle incelemeyi kolaylaştıran bağımsız yolculuk rehberi.

**Site:** [OtobüsYorum](https://otobusyorum.vercel.app/)
